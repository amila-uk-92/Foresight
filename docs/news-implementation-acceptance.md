## External acceptance still blocked

**Live Jev** requires `TYPESAFE_API_KEY`, `FORESIGHT_JEV_ENABLED=1` and an explicitly chosen nonzero budget. Adapter tests use isolated simulated transport; they are not real-provider acceptance.

**Historical news accuracy** requires licensed/permitted, timestamp-valid archive coverage. The forward RSS cannot populate the 36-month training/8-month validation windows retrospectively. Human labels, semantically audited event clusters, source-continuity evidence and fresh forward confirmation still need genuine data. No subscription, account or credit purchase occurred.

Stock/gold composition contracts are supported and tested with isolated profiles/session calendars, but no real stock/gold provider is claimed live. The larger multi-agent design is not finished; see the [29-section conformance audit](specification-conformance-audit.md).
